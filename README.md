# Mark W. Parker portfolio

## Edit the copy

Edit the [website copy document](https://docs.google.com/document/d/1JhgnMsup1rWWVLRu7RcVjCfw3P77X1BioW70EU0H8xs/edit?usp=drivesdk). It contains the current wording organized by page section. Keep the section labels, and change the text beneath them. When ready, ask ChatGPT to **sync the website copy from the document**. Edits to the document do not publish automatically; the HTML is updated and checked before publication.

The site uses no build tools or JavaScript. Typography loads from Google Fonts, with Georgia and Arial fallbacks. Case-study diagrams are CSS and text, so they remain accessible and easy to maintain.
